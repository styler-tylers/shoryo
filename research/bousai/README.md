# 防災研究 — オールハザード型の予測と対策

自然災害とサイバー攻撃を「別々の災害」としてではなく、**同じ枠組みで予測・評価・対策する**ための研究ノート。

- 作成: 2026-10-30
- 状態: 骨格(v0.1)。各章は今後の調査で肉付けする
- 注記: 数値・制度は作成時点の把握に基づく。引用前に一次資料で必ず再確認すること(【要確認】印)

---

## 1. 研究の問い

中心となる問い:

> 地震・風水害などの自然災害と、サイバー攻撃・システム障害などの人為的脅威が**同時に、または連鎖して**起きたとき、社会・組織はどこで壊れ、何を先に備えるべきか。

派生する問い:

1. **予測**: 性質の違うハザード(物理現象 vs. 意図を持つ攻撃者)を、共通の尺度でリスク比較できるか
2. **連鎖**: 停電・通信途絶・物流停止などの「依存関係」を介して、被害はどう波及するか
3. **複合**: 災害の混乱に乗じた攻撃(災害便乗詐欺、復旧中の脆弱な状態への侵入)をどう見積もるか
4. **対策**: 限られた予算で、どの対策が最も多くのハザードに効くか(共通対策の発見)

---

## 2. 統一的なリスクの考え方

自然災害とサイバーで用語は違うが、構造は対応する。

| 共通概念 | 自然災害での呼び方 | サイバーでの呼び方 |
|---|---|---|
| 脅威の発生源 | ハザード(地震・豪雨) | 脅威主体(犯罪集団・国家系) |
| 起こりやすさ | 発生確率・再現期間 | 攻撃頻度・悪用可能性 |
| さらされるもの | 曝露(人口・建物・インフラ) | 攻撃面(公開資産・アカウント) |
| 弱さ | 脆弱性(耐震性・地盤) | 脆弱性(未修正の欠陥・設定不備) |
| 被害 | 人的・物的・経済被害 | 停止時間・情報漏えい・損失額 |
| 回復 | 復旧・復興 | インシデント対応・復旧 |

**決定的な違い**: 自然災害は「意図を持たない」ので統計で予測できるが、攻撃者は**対策を見て行動を変える**(適応的)。このため、サイバーは確率だけでなくゲーム理論的・シナリオ的な扱いが必要になる。この差をどう一つの枠組みに収めるかが研究の核心の一つ。

### 使える分析手法

- **リスク = ハザード × 曝露 × 脆弱性**(自然災害の標準形。サイバーにも転用可)
- **ボウタイ分析**: 原因側の予防策と結果側の緩和策を一枚に整理
- **依存関係グラフ**: 電力 → 通信 → 決済 → 物流 のような連鎖をネットワークとして表現
- **レジリエンス曲線**: 機能が「どれだけ落ちて、どれだけ早く戻るか」の面積で評価
- **シナリオ演習(机上訓練)**: 確率が付けにくい事象を、具体的な筋書きで検証

## 3. ハザード別の予測手法

### 3.1 地震・津波

- 長期評価: 地震調査研究推進本部の発生確率、J-SHIS(確率論的地震動予測地図)
- 南海トラフ: 30年以内発生確率は2025年9月に「60〜90%程度以上」へ表記変更(別計算法では20〜50%)【要確認】
- 南海トラフ地震臨時情報: 2024年8月8日に初の「巨大地震注意」発表(日向灘の地震後)
- 短期: 緊急地震速報、津波警報。**地震の日時を特定する予知は現時点で不可能**という前提に立つ
- 研究上の論点: 「確率は高いがいつかは分からない」情報を、人や組織の行動にどう結びつけるか

### 3.2 風水害・土砂災害

- 数値予報(アンサンブル予報)、線状降水帯の半日前予測、キキクル(危険度分布)
- 気候変動による豪雨頻度の増加 → 過去データだけでは将来を過小評価する問題
- 研究上の論点: 予測の「空振り」が続くと避難行動が鈍る(オオカミ少年効果)

### 3.3 火山・宇宙天気・その他

- 噴火警戒レベル、富士山降灰による首都圏機能停止の想定
- 太陽フレア・磁気嵐(2024年5月に大規模な磁気嵐)→ GPS・通信・電力網への影響。**自然災害とITの接点**として重要
- 感染症パンデミック(人員不足型の事業停止)

### 3.4 サイバー攻撃

- 脅威インテリジェンス: 攻撃グループの手口(MITRE ATT&CK)、JPCERT/CC・IPA の注意喚起
- 悪用予測: CISA KEV(実際に悪用された脆弱性一覧)、EPSS(悪用確率スコア)
- 異常検知: ログ・通信の機械学習による検知
- 定量化: FAIR などのサイバーリスク金額換算手法
- 国内の近年の事例(研究の参照点):
  - 名古屋港コンテナターミナル停止(2023年、ランサムウェア)
  - KADOKAWA(2024年、ランサムウェア)
  - 航空会社・金融機関への DDoS(2024年末〜2025年初頭)
  - アサヒグループ、アスクルのランサムウェア被害による出荷停止(2025年)【要確認】
- 研究上の論点: 攻撃は「頻度は高いが個々は予測困難」。予測より**検知と回復の速さ**に重点が移りつつある

### 3.5 悪意のないシステム障害

- 2024年7月の CrowdStrike 更新による世界的障害、2025年4月のイベリア半島大停電など
- 攻撃でなくても、集中化したITが「単一障害点」になる。サイバー防災の範囲に含めるべき

## 4. 複合災害・連鎖のシナリオ

研究の独自性が出やすい領域。

| シナリオ | 連鎖の筋道 | 着目点 |
|---|---|---|
| 大地震 × 災害便乗攻撃 | 被災 → 寄付・給付金を装うフィッシング、偽の安否確認サイト | 平時より人が騙されやすい心理状態 |
| 大地震 × 復旧中の侵入 | 代替回線・仮設システム・緊急の権限付与 → 防御が手薄に | 「緊急時の例外」が攻撃面になる |
| 豪雨 × 二次災害(能登型) | 地震で弱った地盤・堤防に豪雨(2024年能登:1月地震→9月豪雨) | 復旧途中の脆弱期間 |
| 電力インフラ攻撃 × 猛暑/寒波 | 停電 → 空調停止 → 健康被害 | サイバー被害が人命被害に転化 |
| 磁気嵐 × 通信・測位 | GPS時刻同期の喪失 → 通信網・金融取引 | 自然現象がIT障害として現れる |
| 有事前の潜伏(Volt Typhoon型) | 平時から重要インフラに潜伏 → 危機時に起動 | 予測ではなく「すでに侵入されている」前提 |

## 5. 対策の枠組み

### 5.1 参照すべき枠組み

- **仙台防災枠組 2015-2030**(国連): 災害リスク削減の国際目標。2030年の期限後を見据えた議論も研究対象
- **NIST CSF 2.0**(2024年): 統治・特定・防御・検知・対応・復旧の6機能
- **ISO 22301 / 事業継続ガイドライン(内閣府)**: BCP の標準
- **国内制度の動き**: 能動的サイバー防御関連法(2025年成立)、内閣官房の国家サイバー統括室(2025年発足)、防災庁の設置準備【要確認: 最新の設置時期・権限】

### 5.2 ハザード横断で効く「共通対策」

研究仮説: 以下は自然災害にもサイバーにも効くため、投資効率が高い。

1. **オフライン・不変バックアップ**(地理的分散 + ランサムウェア耐性)
2. **紙と手作業での代替手順**(停電でもサイバー停止でも業務を続ける)
3. **通信手段の多重化**(衛星通信など)
4. **意思決定の事前委任**(誰がいつ何を決めるかを平時に決めておく)
5. **依存先の可視化**(サプライチェーン・クラウド・電力の依存関係マップ)
6. **定期的な演習**(机上訓練 → 実動訓練)

### 5.3 ハザード固有の対策

- 地震: 耐震化、家具固定、津波避難、事前復興計画
- 風水害: 流域治水、ハザードマップ、マイタイムライン
- サイバー: 多要素認証、パッチ管理(KEV 優先)、ゼロトラスト、EDR、インシデント対応計画

## 6. 研究の進め方(案)

| 段階 | 内容 | 成果物 |
|---|---|---|
| 1 | 対象の絞り込み(地域?組織?分野?) | 研究範囲の定義 |
| 2 | 文献・制度・事例の収集 | 文献リスト、事例データベース |
| 3 | 統一リスク評価表の作成 | ハザード横断のリスク一覧(頻度×影響) |
| 4 | 依存関係・連鎖のモデル化 | 連鎖マップ(可視化ツール) |
| 5 | 複合シナリオの作成と机上演習 | シナリオ集、演習結果 |
| 6 | 共通対策の効果比較 | 対策の優先順位表 |

### 歴史資料との接続

このリポジトリの「渉猟」(国会図書館全文検索ツール)は、**歴史災害記録の調査**に使える。古文書・村誌の地震・洪水記録は、観測記録より長い期間の発生履歴を補う一次資料になる(歴史地震学の手法)。地域を絞れば、過去数百年の災害履歴を掘り起こすことができる。
