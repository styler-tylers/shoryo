# 2026-11-10 ヴォイニッチ手稿 定量分析

> [!summary] 要旨
> [[ZL転写ファイル]]（版 3b）を使って、単語頻度・語頭と語尾・行頭と行末・頁ごとの語彙を数えた。
> 文章は自然言語に近い頻度分布（Zipf 指数 1.02）を持つ一方で、字形の位置、行頭・行末、段落頭に強い規則がある。
> 語彙の差を最も大きく生むのは [[Currier 言語]] A/B の違いで、次いで物理的に近い頁（同じ葉・同じ二つ折り）ほど語彙が似ている。

## 方法

- データ: [[ZL転写ファイル]] `ZL3b-n.txt`【B】。対象は [[ヴォイニッチ手稿（Beinecke MS 408）]]【A】の全転写。
- 道具: このリポジトリの `voynich/` にある Python スクリプト（標準ライブラリのみ）。再現コマンドは各節に記す。
- 単語化の既定: `.` と `,` で区切る / 異読 `[a:o]` は最初の読み / `?` を含む語は除外 / 合字 `{ }` は中身を採用。
- 字形の単位: [[EVA]] の `ch` `sh` と台付きガロウズ `cth` `ckh` `cph` `cfh` を 1 字形とする（例: `qokchedy` = q·o·k·ch·e·d·y）。
- 偏りの検定: 2 群の比較は対数尤度比 G²、隣接頁の類似は並べ替え検定。

> [!warning] 方法上の注意
> - 結果はすべて ZL 版の読み（単語の区切り・字形の同定・段落の判定）に依存する。
> - 字形の単位の決め方（`iin` を 1 単位とみなすか等）で語頭・語尾の結果は変わる。
> - 頁の並びは現在の綴じ順であり、元の順番とは違う可能性が高い（[[頁順の問題]]）。「隣り合う頁」の結果は現在の並びでの隣として読む。
> - 筆写者区分 `$H` の出典は未確認（[[ZL転写ファイル]] の注意点を参照）。

## 1. 単語頻度

`python3 voynich/word_freq.py --by L`

| 項目 | 全体 | 言語 A | 言語 B |
|---|---|---|---|
| 頁数 | 226 | 114 | 82 |
| 総語数 | 38,346 | 11,574 | 23,468 |
| 異なり語数 | 8,093 | 3,453 | 4,936 |
| Zipf 指数 | 1.022 | 0.960 | 1.067 |
| 最頻語 | daiin（2.20%） | daiin（4.30%） | chedy（2.11%） |

- 1 回しか出ない語は異なり語の 69.5%。平均語長は EVA で 5.01 文字。
- Zipf 指数が 1 に近いのは自然言語と同様。ただしこれだけでは「意味のある文章」の証拠にはならない（無意味な生成手順でも Zipf 則に近づくことがある）。
- 言語 A の特徴語: `daiin` `chor` `chol` `cthy` `sho`。言語 B の特徴語: `chedy` `shedy` `qokeedy` `qokedy` `qokain`（B で 1.31% の `qokeedy` は A に 1 回も出ない）。

## 2. 語頭・語尾

`python3 voynich/affix.py --by L`

**字形の位置**（その字形の出現のうち、語のどこにあるか）

| 字形 | 主な位置 |
|---|---|
| `q` | 語頭 99.4% |
| `e` `i` `h` | 語中 98〜99.8% |
| `n` | 語末 98.5% |
| `m` | 語末 95.2% |
| `y` | 語末 86.1% |
| `r` | 語末 75.1% |

**よくある語頭・語尾**

- 語頭: `qo-` 14.2%, `che-` 7.7%, `ok-` 6.7%, `ot-` 6.5%, `da-` 6.3%
- 語尾: `-dy` 18.2%, `-in` 15.9%, `-ey` 10.9%, `-ol` 9.4%, `-ar` 7.4%

**語頭と語尾の組み合わせ**（観測値 / 独立を仮定した期待値）

- `a-` × `-in` = 3.0 倍、`d-` × `-in` = 2.1 倍（`aiin` `daiin` 系）
- `sh-` × `-in` = 0.3 倍、`ch-` × `-in` = 0.5 倍（避け合う）
- `sh-` は `-ey`（1.5 倍）`-dy`（1.4 倍）`-ol`（1.4 倍）と組む

**言語 A と B**

- 語尾 `-edy`: B では語の 17.2%、A では 0.2%（A の 11,574 語中 23 語）
- A に多い: 語頭 `cho-` `cth-` `sho-`、語尾 `-or` `-ol` `-chor` `-chol`
- B に多い: 語頭 `qok-` `l-` `ched-` `shed-`、語尾 `-dy` `-ain` `-chdy`

> [!note] 解釈（仮説）
> 語の頭と尾が独立でなく、字形の位置がほぼ固定していることから、語は「語頭部＋語幹＋語尾部」のような決まった枠に字形を当てはめて作られている可能性がある。
> 自然言語の屈折（語尾変化）とも、規則的な生成手順とも両立するので、どちらかを決める証拠にはまだならない。

## 3. 行頭・行末

`python3 voynich/line_position.py --by L`（段落テキスト 4,119 行。比較には 3 語以上の 4,035 行）

**段落の最初の語**（730 段落）

- 84.4% がガロウズ字形（`k t p f` と台付き）で始まる
- `p-` で始まるものは 45.6%。段落の最初でない行頭では 1.3%
- 字形 `p` `f` は段落の最初の行に集中（他の行の約 20 倍 / 15 倍）

**行頭**（段落の最初の行を除き、行中の語と比較）

- 語頭 `y-` `s-` `d-` が行中の 2.5〜5 倍
- `ych-` は 43 倍、`ysh-` は 83 倍
- 語 `dshedy` `saiin` `sol` `sor` が行頭に偏る

**行末**（段落の最後の行を除き、行中の語と比較）

- 語尾 `-m`: 行末の語の 16.9%、行中では 0.95%
- 語尾 `-g` は 28 倍。語 `am` `dam` `oly` が行末に偏る
- 行末の `-m` の偏りは言語 B で 36 倍、言語 A で 6 倍

**語の長さ**: 行の 1 語目が最長（平均 4.97 字形）、2 語目は 4.30、行末の語が最短（4.25）。

> [!note] 解釈（仮説）
> 自然言語の文章なら、行の折り返し位置は語の中身とほぼ無関係なはず。行頭・行末・段落頭でここまで偏るのは、「行」や「段落」が書き手にとって意味のある単位だったことを示唆する。
> 段落頭のガロウズ（特に `p`）は、見出しや装飾的な頭文字のような役割の可能性がある。行末の `-m` は行末を埋める・閉じる記号の可能性がある。

## 4. 語彙の移り変わり

`python3 voynich/vocab_shift.py`（段落テキスト、50 語以上の 193 頁。類似度は単語頻度のコサイン類似度）

| 頁の組 | 組の数 | 平均類似度 |
|---|---|---|
| 全ての組 | 18,528 | 0.236 |
| 言語が異なる（A と B） | 8,829 | 0.167 |
| 同じセクション（挿絵の種類） | 7,993 | 0.253 |
| 同じ言語 | 9,126 | 0.305 |
| 同じクワイア | 1,362 | 0.368 |
| 隣り合う頁 | 192 | 0.384 |
| 同じ二つ折りの別の葉 | 189 | 0.408 |
| 同じ葉の表と裏 | 107 | 0.424 |

- 隣り合う頁（現在の綴じ順）の類似度 0.384 は、頁順をランダムに並べ替えた場合の 0.236 より有意に高い（並べ替え 2,000 回, p = 0.0005）。ただし同じ二つ折り・同じセクションの頁が今も近くにまとまっているためとも説明でき、現在の並びが正しい証拠にはならない（[[頁順の問題]]）。
- 言語 A だけ・B だけに絞っても、同じ葉 ＞ 同じ二つ折り ≈ 隣接 ＞ 全体 の順は変わらない（A: 0.373 / 0.352 / 0.348 / 0.279、B: 0.495 / 0.484 / 0.482 / 0.352）。
- セクション内の類似度は、植物 0.234（全体平均と同程度）、生物・浴場 0.608、星・レシピ 0.476、薬学 0.364。
- 筆写者 2 と 3 は語彙が近い（0.352）。筆写者 1 は他と離れている（0.14〜0.21）。
- 少数の頁に集中する語（話題語の候補）: `qol` `olkain`（生物・浴場 f75〜f83）、`cheal` `lkain`（星・レシピ f108〜f116）、`ytaiin`（f86 の折り込み）。

> [!note] 解釈（仮説）
> 同じ二つ折りの別の葉は、綴じた状態では離れていることが多いのに、隣り合う頁と同じくらい語彙が似ている。
> 二つ折りの紙 1 枚が書写の単位だった、あるいは現在の綴じ順が元の順番と違う、という見方と整合する。
> 植物セクションは挿絵の種類としては 1 つでも、語彙の面ではまとまっていない（言語 A と B の頁が混在するため）。

## 分かったことの整理

| 確度 | 内容 |
|---|---|
| 確定（ZL3b の数え上げとして） | 字形の位置の偏り、`-edy` の A/B 差、段落頭の `p-`、行末の `-m`、物理的に近い頁ほど語彙が似ること |
| 仮説 | 語が「語頭部＋語幹＋語尾部」の枠で作られている / 行・段落が機能的な単位 / 二つ折りが書写の単位 |
| 未検証 | `$H` 筆写者区分の出典 / 放射性炭素年代の一次報告（他の転写での再現は第 2 回で確認済み） |

> [!question] 未解決の問い
> - 行末の `-m` や行頭の `y-` `s-` は、同じ語の「行頭形」「行末形」なのか、別の語なのか。（行頭の `ychedy` と行中の `chedy` の対応など）
> - 二つ折りごとの語彙のまとまりは、筆写者の交代で説明できるか。それとも内容（話題）の違いか。
> - 言語 A と B は、同じ体系の「方言」なのか、書き方の段階の違いなのか。
