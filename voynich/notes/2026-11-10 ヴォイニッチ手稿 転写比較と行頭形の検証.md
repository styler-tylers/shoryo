# 2026-11-10 ヴォイニッチ手稿 転写比較と行頭形の検証

> [!summary] 要旨
> [[2026-11-10 ヴォイニッチ手稿 定量分析]] の「次のアクション」1・2 を実施した。
> (1) 主な結果は高橋健の転写（IT）でもほぼ同じ値で再現し、転写者の読みに依存しない。
> (2) 行頭の `y-`（と `d-`）は、ふつうの語の前に行頭だけで付く字形である可能性が高い。行末の `-m` は行末専用の形とは言えない。

## 1. 転写の比較

`python3 voynich/compare_transcriptions.py ZL3b-n.txt IT2a-n.txt RF1b-e.txt`

使った転写（いずれも voynich.nu で公開、2026-11-10 取得）:

- ZL: René Zandbergen「ZL transliteration file, Version 3b of 13/05/2025」https://www.voynich.nu/data/ZL3b-n.txt 【B】
- IT: 高橋健（Takeshi Takahashi）の転写、LSI 収録の 1999 年版を IVTFF 化したもの「Version 2a of 02/02/2023 modified 25/06/2025」https://www.voynich.nu/data/IT2a-n.txt 【B】
- RF: Zandbergen の「参照転写」。ZL と GC（Glen Claston の v101 転写）を自動で統合したもの。段落記号なし。https://www.voynich.nu/data/RF1b-e.txt 【B】

| 指標 | ZL | IT | RF |
|---|---|---|---|

| Zipf 指数 | 1.022 | 1.006 | 0.977 |
| `q` が語頭 / `n` が語末 | 99.4% / 98.5% | 99.4% / 98.7% | 99.3% / 98.3% |
| 語尾 `-edy`（言語 A / B） | 0.2% / 17.2% | 0.2% / 17.4% | 0.2% / 11.7% |
| 段落頭の語がガロウズ / `p-` | 84.4% / 45.6% | 84.6% / 44.6% | － |
| 行頭 `y-`（行頭 / 行中） | 17.5% / 3.7% | 17.3% / 3.5% | 14.5% / 3.4% |
| 行末 `-m`（行末 / 行中） | 16.9% / 1.0% | 18.1% / 1.0% | 15.5% / 0.9% |
| 類似度: 全体 / 隣接 / 同じ二つ折り / 同じ葉 | .236 / .384 / .408 / .424 | .231 / .377 / .403 / .417 | .208 / .346 / .377 / .377 |
| 上位 100 語のうち ZL と共通 | 100 | 96 | 93 |

- 第 1 回で見つけた規則は、すべて IT でもほぼ同じ値で出る。**転写者の読みの違いに左右されない**。
- RF は稀少文字コード（`@152;` など）を多用する別の表記で、段落記号も無い。異なり語数が多く `-edy` が少なめに出るが、傾向は同じ。

> [!note] 訂正
> 第 1 回の調査ログで「語尾 `-edy` は言語 A で 0.7%」としていたのは誤り。0.7% は「言語 B 以外の全頁（言語未指定の頁を含む）」の値だった。言語 A だけでは 0.2%（11,574 語中 23 語）。第 1 回のノートと README は修正済み。

## 2. 行頭形の検証

`python3 voynich/line_forms.py`（段落テキスト。行頭は段落の最初の行を除き、行中の語と比べる）

**問い**: 行頭に多い `y-` `s-` `d-` で始まる語は、「ふつうの語＋行頭だけで付く字形」なのか。

### 検証 1: 最初の字形を取り除いた残りは、行中の語か → 区別できない

| 字形 | 行頭の語で残りが行中の語 | 行中の語で残りが行中の語（対照） |
|---|---|---|
| `y-` | 81.6% | 81.0% |
| `s-` | 89.7% | 88.4% |
| `d-` | 91.3% | 92.1% |

ヴォイニッチの語は組み合わせの自由度が高く、どの語でも最初の字形を取ると別の既存の語になりやすい。この方法だけでは判定できない。

### 検証 2: 残りはどんな字形で始まるか → 決め手

| | `o` | `ch` | `q` | `sh` | `k` | 近さ |
|---|---|---|---|---|---|---|
| 行中の語全体 | 21% | 18% | 17% | 10% | 4% | － |
| `y-` 行頭の語の残り | 3% | 31% | 0% | 14% | 24% | 0.56 |
| `y-` 行中の語の残り | 1% | 4% | 0% | 1% | 44% | 0.17 |
| `d-` 行頭の語の残り | 8% | 22% | 0% | 16% | 0% | 0.48 |
| `d-` 行中の語の残り | 11% | 5% | 0% | 2% | 1% | 0.30 |

（近さ = 行中の語全体の語頭字形の分布とのコサイン類似度）

- 行頭の `y-` 語は、`y` の後に `ch` `sh` が来るものが 45%（`ycheey` `ychor` `yshey` `ycheol`）。行中の `y-` 語ではそれが 5% しかなく、主に `yk-`（`ykeey` など）。
- つまり行頭では「`y` ＋ ふつうの語（`cheey` `chor` `shey` など）」の形が現れ、行中の `y-` 語とは別の種類の語になっている。`d-` も同様（`dshedy` → `shedy`, `dchedy` → `chedy`）。
- 言語 A・B のどちらでも同じ（`y-` の近さ: A 0.73 対 0.21、B 0.46 対 0.15）。高橋版でも同じ（0.56 対 0.17）。

### 検証 3: 行頭だけに現れる語

語そのものは行中でほとんど使われない（2 回未満）のに、残りは行中の語であるもの:

| 字形 | ZL | IT |
|---|---|---|
| `y-` | 45.3%（234/517） | 39.6%（212/535） |
| `s-` | 27.4%（104/380） | 30.3%（116/383） |
| `d-` | 18.2%（110/606） | 18.2%（110/605） |

例: `ychor` は行頭 15 回・行中 0 回、`chor` は行中 193 回。`ycheey` は行頭 16 回・行中 1 回、`cheey` は行中 166 回。

> [!warning] 検証 3 の限界
> 行中の語は定義上「行中で使われる」ので、行中の語を対照にした同じ割合は計算できない。記述的な数字として扱う。

## 3. 行末形の検証

**問い**: 行末に多い `-m` で終わる語は、ふつうの語の語尾が行末だけ変わったものか。

| 置き換え | 行末の `-m` 語で行中の語になる | 行中の `-m` 語（対照） |
|---|---|---|
| `-m` → `-iin` | 66.6% | 67.2% |
| `-m` → `-r` | 70.4% | 78.7% |
| `-m` → `-l` | 68.2% | 76.7% |
| `-m` → 削除 | 41.4% | 47.8% |

- `dam`↔`daiin`, `qokam`↔`qokain`, `otam`↔`otaiin` のような対応はあるが、行末の `-m` 語と行中の `-m` 語とで差が無い。
- `-m` は `-iin` `-r` `-l` などと入れ替わる語尾の 1 つで、行末に出やすい（行中の約 18 倍）だけ。「行末専用の形」とまでは言えない。

## 分かったことの整理

| 確度 | 内容 |
|---|---|
| 確定（3 転写で再現） | 第 1 回の主な規則（字形の位置、`-edy` の A/B 差、段落頭 `p-`、行頭 `y-`、行末 `-m`、物理的に近い頁ほど語彙が似る） |
| 確定（ZL・IT で再現） | 行頭の `y-` `d-` 語の残りは、行中の語全体と同じように始まる（`ch-` `sh-` が多い） |
| 仮説 | 行頭の `y-` `d-`（`s-`）は、ふつうの語の前に行頭だけで付く字形 |
| 否定的 | 行末の `-m` が特定の語尾の行末専用形であること |

> [!question] 未解決の問い
> - 行頭の `y-` は、取り除くと文として自然につながるのか（前の行の行末の語との関係）。
> - 段落頭の `p-` `t-`（ガロウズ）も、同じように「ふつうの語＋頭の字形」なのか。
> - `-m` が行末に多いのは、行末の余白に合わせた短い語尾の選択なのか。

## 次のアクション
