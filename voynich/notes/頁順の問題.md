# 頁順の問題

> [!summary] 要旨
> [[ヴォイニッチ手稿（Beinecke MS 408）]] の現在の頁の並び（綴じ順）は、書かれた当時の並びと違う可能性が高い。
> 頁をまたぐ絵が確認されていることもその根拠の一つ。分析では「現在の並び」に頼る指標と、紙の物理的な単位（葉・二つ折り）に基づく指標を区別する。

## 前提

- 本研究の立場: **現在の頁の並びは正しくない可能性が高い**ものとして扱う。
- 根拠:
  - 頁をまたいで続く絵が確認されている（研究者本人の所見。該当する頁はまだこのノートに記録していない）。
  - 装丁は 18〜19 世紀の近代のもの【所蔵館の目録記述, B】。

> [!warning] 未記録
> 頁をまたぐ絵の具体的な頁（どの頁とどの頁か）を、このノートに記録すること。
> 記録した組が現在の綴じ順で見開きになっているかを確かめれば、綴じ直しの直接の証拠になる。

## どの分析が頁の並びに依存するか

| 分析 | 頁の並びへの依存 | 扱い |
|---|---|---|
| 単語頻度（`word_freq.py`） | なし | そのまま使える |
| 語頭・語尾（`affix.py`） | なし | そのまま使える |
| 行頭・行末（`line_position.py`, `line_forms.py`） | ほぼなし（頁の中の行だけを見る） | そのまま使える。ただし段落が前の頁から続いている場合、頁の最初の行を「段落の途中」と判定できない可能性がある |
| 語彙の類似度: 隣り合う頁 | **あり**（現在の綴じ順の隣） | 「現在の並びでの隣」として扱い、元の並びの証拠には使わない |
| 語彙の類似度: 同じ葉の表と裏 | なし（紙の表裏は綴じ直しても変わらない） | 最も信頼できる |
| 語彙の類似度: 同じ二つ折りの別の葉 | ほぼなし（二つ折りの紙 1 枚は綴じ直しても一体） | 信頼できる。ただし二つ折りが切り離されて組み直された場合は別 |
| 語彙の類似度: 同じクワイア | あり（クワイアの構成自体が後の綴じ方による可能性） | 参考程度 |

## これまでの結果の読み直し

[[2026-11-10 ヴォイニッチ手稿 定量分析]] の語彙の類似度:

| 頁の組 | 平均類似度 | 頁の並びへの依存 |
|---|---|---|
| 同じ葉の表と裏 | 0.424 | なし |
| 同じ二つ折りの別の葉 | 0.408 | ほぼなし |
| 現在の綴じ順で隣り合う頁 | 0.384 | あり |
| 全ての組 | 0.236 | なし |

- 紙の物理的な単位（葉・二つ折り）で見た類似度の方が、現在の綴じ順での隣より高い。
- これは「二つ折りの紙 1 枚ごとに書かれ、後で並びが変わった」という見方と整合する。
- 現在の並びでの隣接頁の類似度がランダムより高い（p = 0.0005）のは、同じ二つ折り・同じセクションの頁が今も近くにまとまっているためとも説明でき、「現在の並びが正しい」ことの証拠にはならない。

## 次のアクション

1. 頁をまたぐ絵の組を記録し、[[ヴォイニッチ手稿（Beinecke MS 408）]] の IIIF 画像で確認する（頁番号・画像のコマ番号を残す）
2. その組が現在の綴じ順で見開き（左頁 = ある葉の裏、右頁 = 次の葉の表）になっているかを調べる
3. 語彙の類似度から、二つ折り単位での元の並びを推定する（似ている二つ折りを近くに置く並べ替え）。絵のつながりと一致するかで検証する
4. 段落が頁をまたいで続いていそうな箇所（頁の最初の行に段落頭の印が無い頁）を洗い出す
