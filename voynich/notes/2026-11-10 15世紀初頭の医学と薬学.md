# 2026-11-10 15世紀初頭の医学と薬学

> [!summary] 要旨
> [[ヴォイニッチ手稿（Beinecke MS 408）]] の羊皮紙の年代（1404〜1438）の医学・薬学を、写本の各部（植物・黄道・浴場・薬学・レシピ）と比べるために整理した。
> 当時の医学は、**体液説を土台に、占星術で時を選び、食事・入浴・薬草で体の釣り合いを整える**体系だった。写本の主題は、ほぼすべてこの体系の中に場所がある。
> 時代背景の全体は [[2026-11-10 15世紀初頭の宗教・哲学・法・科学・錬金術・数学]] を参照。

## 医学の考え方

- **体液説**: 体は血液・粘液・黄胆汁・黒胆汁の四つの体液でできていて、その釣り合いが崩れると病気になる。四体液は熱・冷・乾・湿の性質と、四元素・四季・人生の時期に対応する。人それぞれの体質（気質、complexio）は四体液の混ざり方で決まる。
- **六つの非自然事物**: 空気、飲食、運動と休息、睡眠と覚醒、排泄と保持（入浴や瀉血を含む）、心の動き。これらを調整して健康を保つのが「養生（レギメン）」で、医学の大きな部分を占めた。
- **診断**: 尿を見る（尿の色を表にした図＝尿色輪がよく描かれた）、脈をとる、体質と季節と星の位置を考える。
- **治療**: 食事の指示、瀉血（血を抜く）、下剤・吐剤、入浴、薬（単味薬・合成薬）。
- **医療占星術**:
  - 月が黄道のどの宮にあるかで、体のどの部位に瀉血や手術をしてよいかが決まった。獣帯人体図（ゾディアック・マン）はそのための図。
  - 瀉血人体図（どの血管から抜くか）、病気が峠を迎える日（分利日）の計算、薬草を摘む時期の選択にも星を使った。
  - 医師は折りたたみ暦や携帯用の天文表を持ち歩いた。

## 教育と教科書

- **大学医学部**: ボローニャ、パドヴァ、パヴィア、パリ、モンペリエが中心。ウィーン、プラハ、オックスフォードでも学べた。医学博士になるには、教養課程を終えたあと 5〜6 年かかった。
- **教科書**:

| 書名 | 内容 |
|---|---|
| 『アルティケッラ（Articella）』 | 入門書の合本。ヒポクラテス『箴言』、ガレノス『医術』、尿と脈の小論など |
| アヴィケンナ（イブン・シーナー）『医学典範』 | 医学の総合書。大学の講義の中心 |
| ラーゼス（ラーズィー）『マンスールの書』第 9 巻 | 頭から足までの病気の治療 |
| ガレノスの諸著作 | ラテン語訳。14 世紀から多く読まれる |
| モンディーノ『解剖学』（1316） | 解剖の手引き |
| ギー・ド・ショリアック『大外科学』（1363） | 外科の標準書 |

- **新しい形式**:
  - 実際の症例への医師の意見書（コンシリア）が集められ、本になった。パドヴァのバルトロメオ・ダ・モンタニャーナの意見書集がよく知られる。
  - 『実践（Practica）』と呼ばれる、治療を体系的にまとめた書物も多く書かれた。

## 医療の担い手

- **内科医（physicus, medicus）**: 大学出の学者。ラテン語の書物と理論を扱い、手は使わない。
- **外科医・理髪外科医**: 手術、骨折、傷、瀉血を行う。同業組合で修業する職人で、俗語の書物が多い。
- **薬種商（スペツィアーレ、アポテーカー）**: 薬の調合と販売。香辛料、砂糖、蝋、絵具の商人でもあった。
- **産婆と女性の治療者**: 出産と女性の病気。書物にはほとんど残らない。
- **経験家（エンピリク）、ユダヤ人医師、修道院の医療**: ユダヤ人医師は宮廷や都市に多く雇われ、アラビア語・ヘブライ語の医学書の仲介者でもあった。
- **資格**:
  - パリやイタリアの都市では、医師の団体（コッレッジョ）が開業を許可した。
  - イングランドでは 1421 年に学位のない者の開業禁止が議会で認められたが、実施されなかった。

## 外科と解剖

- 外科はギー・ド・ショリアックの体系が標準。戦争（百年戦争、フス派戦争、イタリアの傭兵戦争）で、矢傷や新しい銃創の治療が求められた。
- 解剖はボローニャ・パドヴァで教育として行われた。処刑された罪人の遺体を使い、年に数回、規則に従って行うもの。病気の原因を探るための解剖（死因の検査）も記録に残る。

## 女性の医学

- 『トロトゥーラ』（12 世紀、サレルノ）の系統の婦人科書が、ラテン語と各国語で読まれていた。
- 偽アルベルトゥス『女性の秘密について（De secretis mulierum）』は、受胎・胎児の発育・星の影響を論じた書。医学というより自然哲学の書で、聖職者向けの「秘密の知識」として広まった。
- グアイネーリ『子宮について』は、この時期のイタリアの大学医学による婦人科書。
- **ヴォイニッチ手稿との関係**:
  - Brewer と Lewis（2024、*Social History of Medicine*）は、写本の一部が性と受胎に関わる内容ではないかと論じた。九つのロゼットの頁を受胎の理解を表した図と読み、同時代のハルトリープが「女性の秘密」を秘密の文字で隠すよう勧めていたことを文化的な背景とする。
  - 著者自身、ハルトリープを作者とは考えていない。また写本の解読に基づく主張ではない。

## 入浴療法

- **温泉の医学**:
  - ナポリ近郊ポッツオーリの温泉を詩と絵で描いた『ポッツオーリの温泉について』の写本が、14〜15 世紀にも作られ続けた。
  - パドヴァ近郊のアーバノなど、エウガネイ丘陵の温泉については、パドヴァ大学の教授たちが論じた（ジョヴァンニ・デ・ドンディ、モンタニャーナ、サヴォナローラ）。どの病気にどの温泉が効くか、入る時期、時間、回数を細かく指示した。
- **バーデンの温泉（1416）**:
  - ポッジョ・ブラッチョリーニは、コンスタンツ公会議の滞在中にスイスのバーデンの温泉を訪ね、ニッコリへの手紙に書いた。
  - 男女が同じ湯に入り、湯に浮かべた机で食事をし、上の回廊から見物人が話しかける社交の場として描いている（男女の仕切りについては資料によって読みが違う）。
  - **写本の浴場の部と同じ年代・同じ地域の、入浴する裸の人々の同時代の記述**として重要。
- **都市の風呂屋**: ドイツ語圏・ボヘミアの都市には蒸し風呂（バーデシュトゥーベ）が多くあった。風呂屋は理髪外科医を兼ね、瀉血や吸い玉をした。湯女はヴァーツラフ 4 世の宮廷写本にも描かれている。
- **養生書の挿絵**: 『健康全書（Tacuinum sanitatis）』は、11 世紀バグダードのイブン・ブトラーンの養生書をもとにした絵入りの写本。ロンバルディアで 1380〜1400 年頃に豪華な写本が作られた（ウィーン、パリ、リエージュ、ローマのカサナテンセ図書館）。植物・食べ物・季節・活動の効能を、一項目一図で描く。

## ペストと公衆衛生

- 黒死病（1347〜51）の後も、ペストは 10〜20 年ごとに流行を繰り返した。医師は『ペストについて（De peste）』の意見書を多く書いた（グアイネーリ、プラハティツェのクリシュチャンなど）。原因は悪い空気（ミアズマ）と星の配置とされた。
- **ヴェネツィアの隔離病院（ラッツァレット）**: 1423-08-28、ヴェネツィア元老院がサンタ・マリア・ディ・ナザレト島にペスト患者の隔離施設を設けた。**常設の隔離病院としては最初**とされる。「ラッツァレット」の語源もこの島の名前とされる（異説あり）。
- ミラノなどでは、ペストの流行時に衛生の役所が置かれ、旅行者の健康証明や都市の閉鎖が行われた。

## 薬学

- **単味薬と合成薬**: 一種類の植物・鉱物・動物の素材をそのまま使う薬を「単味薬（シンプリキア）」、何種類も混ぜて作る薬を「合成薬」と呼んだ。素材ごとに熱・冷・乾・湿の度合い（1〜4 度）が決まっていて、病気の性質と逆の性質の薬を当てた。
- **薬種商の標準書**:

| 書名 | 内容 |
|---|---|
| 『キルカ・インスタンス（Circa instans）』（12 世紀、サレルノ、プラテアリウス作とされる） | 単味薬の事典。アルファベット順。絵入りの写本は『薬草論（Tractatus de herbis）』の系統になる |
| 『ニコラウスの解毒薬集（Antidotarium Nicolai）』（12 世紀、サレルノ） | 合成薬の処方集。薬種商が従うべき標準とされた |
| 偽メスエ（偽マーサワイヒ）の『解毒薬集（グラバディン）』など | 合成薬の処方と、下剤の扱い。13〜14 世紀に広まる |
| セラピオン（イブン・ワーフィド系）『集成の書』 | アラビア語の薬物学。パドヴァの『カッラーラ本草』はこのイタリア語訳に絵を付けたもの |
| ディオスコリデス『薬物誌』 | ラテン語訳が流通。ギリシア語原典が人文主義者の関心を引き始める |
| マケル『薬草の効能について』 | 薬草の詩。ドイツ語・英語にも訳された |

- **剤形**: 舐め薬（エレクトゥアリウム）、シロップ、丸薬、粉薬、軟膏、膏薬、蒸留水、油。
- **テリアカ**:
  - 60 種類以上の素材を混ぜた万能の解毒薬。ヴェネツィアが主な産地だった。
  - 素材を公開で並べ、役人の監視のもとで調合した（この方式の記録は主に 16 世紀以降）。
- **蒸留**: ルペシッサの『第五元素』以来、薬草の蒸留水や蒸留酒（アクア・ヴィタエ）が薬として作られた。薬学と錬金術の境目は曖昧だった。
- **薬局の容器**:
  - 薬を保存する筒形の陶器の壺（アルバレッロ）。スペインのバレンシア地方（マニセス）の金彩陶器が輸入され、15 世紀にはイタリアでも作られるようになった。
  - 写本の薬学の部には、植物の部分（根・葉）と並んで容器が描かれている。アルバレッロと比べられてきたが、形の細部は違うという指摘もある（底が胴より広い）。
- **規制**: 薬種商は同業組合（フィレンツェの医師・薬種商組合、ヴェネツィアの薬種商の組合）に属し、規約で薬の質や処方の順守を求められた。都市の公式の処方集はまだなく、『フィレンツェ処方集』は 1499 年。
- **香辛料の交易**: 胡椒、シナモン、サフラン、ショウガなどの香辛料は、食品であり薬でもあった。ヴェネツィアがアレクサンドリア経由で東方から輸入し、ヨーロッパに流した。

## 本草図譜の系統

| 系統 | 年代・場所 | 絵の性格 |
|---|---|---|
| 『薬草論（Tractatus de herbis）』 | 14 世紀〜、北イタリア・南フランス | 図式的な絵と写実的な絵の両方。写して伝えるうちに形が崩れる |
| 『カッラーラ本草』 | 1400 年頃、パドヴァ | 自然をよく観察した写実的な絵 |
| 『健康全書（Tacuinum sanitatis）』 | 1380〜1400 年頃、ロンバルディア | 植物を農作業や人物と一緒に描く |
| プラハティツェのクリシュチャンの本草 | 15 世紀前半、プラハ | ボヘミアで最初のラテン語の本草（ラテン語版とチェコ語版で内容が違う） |
| 『ロッカボネッラ本草』 | 15 世紀半ば、ヴェネツィア | 写実的。この時期より後 |

- 写本の植物の絵は、根・茎・葉・花を一株まるごと、図式的に描く。実在の植物と特定できるものは少ない。この点は、写して伝わるうちに形が崩れた『薬草論』系の写本の絵と似た状態にある、という比べ方ができる。

## ヴォイニッチ手稿の各部との対照

| 写本の部 | 同時代の医学・薬学で対応するもの |
|---|---|
| 植物（Herbal） | 単味薬の事典（『キルカ・インスタンス』『薬草論』）、本草図譜 |
| 天文・黄道（Astronomical, Zodiac） | 医療占星術の暦、獣帯人体図、薬草を摘む時期・瀉血の時期の表 |
| 宇宙論（Cosmological）・ロゼット | 宇宙と体の対応図。受胎の理解の図とする説（Brewer & Lewis 2024） |
| 浴場（Biological） | 温泉療法の書、都市の風呂屋、養生書の入浴の図、ポッジョのバーデンの手紙。女性の体と受胎の書とする説 |
| 薬学（Pharmaceutical） | 薬種商の容器と、植物の根・葉。合成薬の材料の一覧 |
| 星とレシピ（Recipes） | 処方集（解毒薬集）、意見書。短い段落の一つ一つが一つの処方という形式は、処方集とよく似る |

> [!question] 医学・薬学の観点からの問い
> - 写本のレシピの部の段落の数・長さは、同時代の処方集（『ニコラウスの解毒薬集』など）の一項目の長さと比べられるか。段落頭の星の印は、処方集の見出し記号と同じ働きか。
> - 薬学の部の容器の形を、15 世紀前半の薬局の容器（アルバレッロ、木の箱、ガラス瓶）の実物と比べるとどうなるか。
> - 浴場の部の女性たちは、温泉療法（病気の治療）、風呂屋（日常）、受胎（女性の医学）、錬金術（象徴）のどれに最も近いか。どれか一つに決める根拠はあるか。

> [!note] 検証の結果
> 上の問いのうち 3 つを転写データで数えた結果は [[2026-11-10 ヴォイニッチ手稿 医学書仮説の 3 つの検証]] にある。黄道の各宮のラベルは 30（予測どおり）、薬学のラベルは植物の部の本文と偶然以上には一致しない（予測に反する）、レシピの部は短くそろった段落（弱く合う）。

## 次のアクション

1. 『ニコラウスの解毒薬集』の写本（デジタル画像）で、一つの処方の長さと見出しの記号を調べる。写本のレシピの部の段落と比べる（[[2026-11-10 ヴォイニッチ手稿 定量分析]] の行・段落の集計を使う）。
2. Brewer & Lewis（2024）の論文本文を読み、ロゼットの頁の読み方の根拠を確認する。
3. ポッジョのバーデンの手紙のラテン語原文（『ニッコリ宛書簡』）と信頼できる翻訳を探す。
4. 『健康全書』の入浴の図、『ポッツオーリの温泉について』の写本の図と、写本の浴場の部を並べて比べる。
5. プラハティツェのクリシュチャンのラテン語本草（Stehlíková 2017 の研究）に絵があるかを確認する。
