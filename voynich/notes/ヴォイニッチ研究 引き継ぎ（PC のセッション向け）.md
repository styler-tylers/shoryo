## いまの圧縮点 `・₃`（2026-11-15）

> ヴォイニッチの行は、**端と内側の 2 層**を持つ。内側の語は、近くの行（10 行ほどまで、近いほど強く）の語を手本に、似た語として作られる（ZL・IT の 2 つの転写、2 つの字形の区切り方で観察）。端の語はこの写しに加わらず、前後の行ともつながらない。字形の並びは音節単位の規則的な表記と構造が似る。平文の存在は保留。

## 次の作業の候補

1. **端の作り方を直した 2 層のモデル**: 端の語に印を付けず「写しに加わらない」だけにして、行頭だけの語の割合（32%）と 8 つの量を保てるか（`voynich/nevo_round3.py` の `two_layer` を元に）
2. **内側の手本は意味によるか**: 絵が同じ種類の頁どうしで、頁をまたいでも似た語の共有が強いか
3. **語末の変わりにくさ**: 写すときに変える位置を語頭・語中に限ると、T1（語末 ≤ 25%）が出るか

## 動かし方

```sh
git clone https://github.com/styler-tylers/shoryo && cd shoryo
git checkout claude/voynich-manuscript-research-csb1hd
python3 -m unittest discover voynich        # 51 件
python3 voynich/nevo_round3.py <Caesar> <Descartes> <Dante>
```

- 転写ファイル（ZL3b-n.txt, IT2a-n.txt）は初回に voynich.nu から自動で取得して `voynich/data/` に置く（git には入れない）
- 参照のテキストは Project Gutenberg: Caesar『ガリア戦記』pg218、Descartes『省察』pg23306、Dante『神曲』pg1012（イタリア語）。`*** START` 〜 `*** END` の本文を使う
