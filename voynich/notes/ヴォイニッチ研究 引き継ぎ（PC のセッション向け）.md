## いまの圧縮点 `・₁₅`（2026-11-15）

> 欄を結び付けた語の型・頻度を合わせた符号表・型で出やすい語ほど写す手順・行の回転・境目の規則・行の端の扱いを組み合わせたモデルが、言語 A・B の両方で 8 つの量・語の家族の変わり方・隣の行との語彙の共有を再現する（構造類似）。A・B の違いの多くは語の型の違い。境目の規則は語全体の選び方に働く。行の位置ごとの型（2 語目 `sh-`/`ch-`、最後 `-m`）は別の規則。平文の有無は保留。

## 次の作業の候補

1. **同音異字型の符号**: 平文の語ごとに型で出やすい語を複数持ち、前の語の終わりと行の位置に合う語を選ぶ（`voynich/nevo_round12.py` の `build12`、`voynich/nevo_round13.py` の `matched_source` を元に）
2. **種を複数にした判定のやり直し**
3. **語の長さの歪度の分解**

## 動かし方

```sh
git clone https://github.com/styler-tylers/shoryo && cd shoryo
git checkout claude/voynich-manuscript-research-csb1hd
python3 -m unittest discover voynich        # 51 件
python3 voynich/nevo_round15.py <Caesar>    # 最新の巡
```

- 転写ファイル（ZL3b-n.txt, IT2a-n.txt）は初回に voynich.nu から自動で取得して `voynich/data/` に置く（git には入れない）
- 参照のテキストは Project Gutenberg: Caesar『ガリア戦記』pg218、Descartes『省察』pg23306、Dante『神曲』pg1012（イタリア語）。`*** START` 〜 `*** END` の本文を使う
