## いまの圧縮点 `・₂₃`（2026-11-16）

> 語は長さの枠と語の端の専用の字形を持つ単位で、欄を結び付けた型から作られる。語と語の境目には `-y→q-`・`-r→a-` のような字形の組ごとの強い規則があり、向きは母音・子音の交代と同じ、強さはウェールズ語並み。語の選び方そのものが境目に合わせられている（後から書き換えると h2 が崩れる）。行は前後と切れ、内側の語の 4 割ほどは近くの行を手本に作られ、位置ごとの型がある。平文の有無は保留。

## 次の作業の候補

1. 境目の字形の規則を語の選び方に入れる（前の語の最後の字形を条件に語を選ぶ）
2. 境目の規則の表を具体的な音の候補と照らし合わせる
3. 言語 A の `d-` で始まる語を作れる型

## 動かし方

```sh
git clone https://github.com/styler-tylers/shoryo && cd shoryo
git checkout claude/voynich-manuscript-research-csb1hd
python3 -m unittest discover voynich        # 51 件
python3 voynich/nevo_round23.py <文章 …>   # 最新の巡（数分）
```

- 転写ファイル（ZL3b-n.txt, IT2a-n.txt）は初回に voynich.nu から自動で取得して `voynich/data/` に置く（git には入れない）
- 参照のテキストは Project Gutenberg: Caesar『ガリア戦記』pg218、Descartes『省察』pg23306、Dante『神曲』pg1012（イタリア語）。`*** START` 〜 `*** END` の本文を使う
