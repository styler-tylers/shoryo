## いまの圧縮点 `・₁₇`（2026-11-15）

> 語は長さの枠を語頭・中・語末の欄で埋める型から作られ、頻度も型に従う。行の内側の語の 4 割ほどは書いた順に近い行の語を手本に語末を保って少し変えて作られる。行と行のつながりは切れ、境目では前の語の終わりに次の語の始まりが合わせられる（語頭だけが違う組から選ぶと B と 2 語目の型が出る）。行の端は写しに加わらず、位置ごとの型がある。平文の有無は保留。

## 動かし方

```sh
git clone https://github.com/styler-tylers/shoryo && cd shoryo
git checkout claude/voynich-manuscript-research-csb1hd
python3 -m unittest discover voynich        # 51 件
python3 voynich/nevo_round17.py <Caesar>    # 最新の巡（時間がかかる: 10〜20 分）
```

- 転写ファイル（ZL3b-n.txt, IT2a-n.txt）は初回に voynich.nu から自動で取得して `voynich/data/` に置く（git には入れない）
