## いまの圧縮点 `・₃₀`（2026-11-16）

> 語は長さの枠・語頭／芯／語末の欄・端の専用の字形を持つ単位で、欄を結び付けた型から作られる。語と語の境目には字形の組ごとの強い規則がある（向きは母音・子音の交代と同じ、強さはウェールズ語並み）。行は前後と切れ、位置ごとの型を持つ。数頁〜20 頁にわたる語彙のまとまりがあり、綴じの単位（A では 1 枚の紙にも）に従い、語そのものではなく語の芯が担う。平文の有無は、調べたどの量でも決まらない。

## 次の作業

- 圧縮点は `・₄₇`（詳しい記録の第 149〜150 節）。**ロードマップの 5 段・時代背景の仮説は閉じた**。第 46・47 巡で近年の研究の材料（トリテミウスの暗号、人が書いた意味のない文章）を測った。意味のない文章は書き手ごとに測ると行の独立と隣の行のくり返しでヴォイニッチと同じ。**語末がほとんど変わらない（13〜17%）ことは、比べた全ての文章に無いヴォイニッチだけの性質**。次は、語末の固さが語末の字形の少なさだけで説明できるかを確かめる
- **最新のまとめ: [[2026-11-17 ヴォイニッチ手稿 研究全体のまとめ（nēvo 第40巡まで）]]**（観察・構造類似・棄却・平文の有無・分からないことの分類・先行研究との表・方法・残した問い）
- 第 2 段の到達点: 平文なしのモデルで A 17/22・B 20/22（`nevo_round34.py` の `build34`。A は `c=0.4, mark=0.25`、B は `c=0.6, mark=0.12, live=True`）。第 4 段の結論: 語・行・頁の統計では平文の有無は決まらない（分類 ⑤）
- 次に開くなら（第 131 節の候補）: (1) 写した語も前の語の最後の 2 字形に合わせて頭と芯の最初の字形を替える（隣り合う語のつながり）、(2) 写して替える場所に語末の欄と欄の境目を足す（言語 A の少し替えて写す）、(3) 話題のある鎖でも偏らない「順番に固有の 1 つ飛び」の測り方を作り物で先に作る、(4) Stolfi の層の切り方で N34 の型の検定をやり直す
- 注意:
  - 頁どうしの語の重なりは**頁の長さに左右される**。言語 B は必ず各頁の語の数をそろえて測る（N90・N95 で 2 度訂正した）
  - モデルは**ヴォイニッチと同じ語の数**（A 11300・B 23091）で作って採点する（N99）。最新のモデルは `nevo_round34.py` の `build34`
  - 採点で定義できない値（語 × 語の結び付きが 0 以下）は外れとして数える
  - 直す前に、まず原因を測る（部品を 1 つずつ足す）。第 35 巡はこの形で予測 10 のうち 9 が当たった
  - **新しい量は、いまの最良のモデルの出力（既知の性質がほぼ全て入る）でも確かめる**。第 42・43 巡の事後の点検 2 つは、どちらも既知の性質（同じ語のくり返し・行の位置の型）を拾っていた
  - **作り物のデータには、本物の持つ性質（同じ語のくり返しなど）も入れる**。入れないと偽の正の結果を見逃す（N127）
  - **測り方は、答えが分かっている作り物のデータで先に確かめる**（N118: 行の引き直しの幅は元の値を含まず、式で出す基準は種類が多いとずれた）
  - 事後に気づいた「発見」は、事前に決めた測り方で確かめるまで「観察」に留める（第 39 巡の 2 つは第 40 巡で取り下げた）
  - 割り算の指標は、分母が小さい文章でぶれる（N115・N116a）。差そのものと誤差の幅で見る
  - 隣り合う語のつながりの残り半分は、事後の仮説を 3 つ立てて 3 つとも外れた。次に手を付けるなら、仮説の前に測り方を作る
  - モデルのどの部品が原因かをコードから推測する前に、ヴォイニッチの側を測る（N108・N109 で見立てが 2 度外れた）
  - 部品を全部足すと打ち消し合う（N106）。足すたびに 22 の量を全部見る
  - 言語 A の基準の「境目%（語 × 語）」は測るたびに 0.35〜0.47 と動く
  - まとまりが 1 に近いモデルでは「置き換えで残る割合」は大きくぶれる。判定に使わない
- そのあと、第 4 段（平文の有無に決着）・第 5 段（まとめ）

## Obsidian との同期

- vault（iCloud）にはクラウドのセッションから直接つなげない。リポジトリ `styler-tylers/-` のブランチ `obsidian-voynich` に、`voynich/notes` の中身（`blind_raters_*` を除く）を写して同期している。巡ごとに、作業用のブランチにプッシュしたあと、このブランチにも写してプッシュする

## 動かし方

```sh
git clone https://github.com/styler-tylers/shoryo && cd shoryo
git checkout claude/voynich-manuscript-research-csb1hd
python3 -m unittest discover voynich        # 51 件
python3 voynich/reproduce.py list           # 主な検定 16 個の一覧（記録の節・目安の時間つき）
python3 voynich/reproduce.py fetch          # 比べる文章 6 冊を voynich/data/texts に取ってくる
python3 voynich/reproduce.py run n104       # 例: 最良のモデルの採点（40 分ほど）
python3 voynich/nevo_round41.py check|n122|n123|n124   # 最新の巡
```

- 転写ファイル（ZL3b-n.txt, IT2a-n.txt）は初回に voynich.nu から自動で取得して `voynich/data/` に置く（git には入れない）
- 参照のテキストは Project Gutenberg: Caesar『ガリア戦記』pg218、Descartes『省察』pg23306、Dante『神曲』pg1012（イタリア語）、ウェールズ語 pg67424・pg14354、アイルランド語 pg50913、Culpeper『Complete Herbal』pg49513。`*** START` 〜 `*** END` の本文を使う
