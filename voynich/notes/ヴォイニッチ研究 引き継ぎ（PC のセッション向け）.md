## いまの圧縮点 `・₉`（2026-11-15）

> `・₈` の手順（行の内側の語を書いた順に近い行の短い語から写し語の終わりを保って一部を変える・行と行のつながりを切る・前の語の終わりに次の語の始まりを合わせる・行の端は写しに加わらず行頭の 4 分の 1 に頭の印）は、ヴォイニッチの行と語の並び方の性質をほとんど再現する。しかし語そのものの形（長さが左右対称にそろう・字形の並びの決まりやすさ・語中で変わる語の家族）は、平文を音節の表記で写すだけでは出ない。語の形は決まった型から作られている可能性が高い。平文の存在は保留。

## 次の作業の候補

1. **語の型から語を作るモデル**: 第 17 回の語の文法や Stolfi の殻の模型で語を作り、`・₈` の並び方の手順（`voynich/nevo_round8.py` の `apply_rule`、`voynich/nevo_round6.py` の `build`）と組み合わせて、語の長さの形・h2・言語 B の T1 が出るか
2. **行の長さのばらつき・行末の語の長さ**: 行の作り方を見直す
3. **平文の有無を見分ける量**: 語の型から作るモデル（平文なし）と平文ありのモデルを同じ土俵で比べる

## 動かし方

```sh
git clone https://github.com/styler-tylers/shoryo && cd shoryo
git checkout claude/voynich-manuscript-research-csb1hd
python3 -m unittest discover voynich        # 51 件
python3 voynich/nevo_round9.py <Caesar>     # 最新の巡
```

- 転写ファイル（ZL3b-n.txt, IT2a-n.txt）は初回に voynich.nu から自動で取得して `voynich/data/` に置く（git には入れない）
- 参照のテキストは Project Gutenberg: Caesar『ガリア戦記』pg218、Descartes『省察』pg23306、Dante『神曲』pg1012（イタリア語）。`*** START` 〜 `*** END` の本文を使う
