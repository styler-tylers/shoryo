# ヴォイニッチ手稿 単語頻度・語頭語尾分析

René Zandbergen の **ZL 転写ファイル**（IVTFF 形式・EVA 表記, 版 3b / 2025-05-13）を読み込み、
単語の頻度・基本統計・Zipf 指数を出力するスクリプトです。標準ライブラリのみで動作します（Python 3.9+）。

- 転写ファイル: https://www.voynich.nu/data/ZL3b-n.txt （初回実行時に `voynich/data/` へ自動ダウンロード。リポジトリには含めません）
- 原本画像: Yale Beinecke MS 408 — https://collections.library.yale.edu/catalog/2002046

## 使い方

```sh
python3 voynich/word_freq.py                         # 全体の上位 30 語と基本統計
python3 voynich/word_freq.py --top 100 --csv voynich/out/freq.csv   # 全語の頻度表を CSV へ
python3 voynich/word_freq.py --language A            # Currier 言語 A のページのみ
python3 voynich/word_freq.py --illustration H --locus P   # 植物セクションの本文（ラベル除外）
python3 voynich/word_freq.py --by L                  # 言語 A / B を比較（特徴語つき）
python3 voynich/word_freq.py --by I --top 10         # 挿絵種別ごとに比較
python3 voynich/word_freq.py --help                  # 全オプション
```

### 絞り込み（カンマ区切りで複数可）

| オプション | 意味 | 値 |
|---|---|---|
| `--language` | Currier 言語 | `A`, `B` |
| `--hand` | 筆写者（Lisa Fagin Davis の分類） | `1`〜`5` |
| `--illustration` | 挿絵種別 | `H` 植物, `A` 天文, `C` 宇宙論, `Z` 黄道, `B` 生物, `P` 薬学, `S` 星, `T` 文字のみ |
| `--quire` | クワイア | `A`〜`T` |
| `--page` | ページ | `f1r,f1v` など |
| `--locus` | 行の種類 | `P` 段落, `L` ラベル, `C` 円形, `R` 放射状 |

### 比較（`--by`）

ページ属性（`L` 言語, `H` 筆写者, `I` 挿絵, `Q` クワイア など）でグループに分け、
グループごとに統計・頻度表と **特徴語**（そのグループで他より有意に多い語。対数尤度比 G² で順位付け）を出力します。
属性が未指定のページは「未指定」グループになります。

## 単語化のルール（既定値）

| ZL の記法 | 意味 | 既定の扱い | 変更オプション |
|---|---|---|---|
| `.` | 単語区切り | 区切る | — |
| `,` | 不確かな単語区切り | 区切る | `--comma-join` で連結 |
| `[a:o]` | 異読 | 最初の読みを採用 | `--alt 1` で 2 番目 |
| `{ckh}` | 合字 | 括弧を外して中身を採用 | — |
| `?` | 判読不能文字 | その語を除外 | `--keep-uncertain` |
| `@185;` | 稀少文字 | そのまま 1 語に含める | `--drop-rare` で除外 |
| `<->` `<~>` | 挿絵による中断 | 単語区切り | — |
| `<!...>` `<%>` `<$>` | コメント・段落の始まり/終わり | 削除 | — |

注意:
- 筆写者・言語などの属性は**ページ単位**で判定します。行中の筆写者交代マーク（`<@H=2>` など、f115r の 2 箇所のみ）は反映しません。
- 平均語長は EVA の文字数です。`ch` や `sh` のように 2 文字で 1 字形を表すものも 2 文字と数えます。

# 語頭・語尾分析（`affix.py`）

単語を EVA の**字形単位**に分けて、語頭（接頭部）と語尾（接尾部）を調べます。
`ch` `sh` と台付きガロウズ `cth` `ckh` `cph` `cfh` は 1 字形、稀少文字 `@nnn;` も 1 字形として扱います
（例: `qokchedy` → `q o k ch e d y`）。絞り込み・`--by`・単語化の設定は `word_freq.py` と共通です。

```sh
python3 voynich/affix.py                    # 全体
python3 voynich/affix.py --by L             # 言語 A / B の特徴的な語頭・語尾
python3 voynich/affix.py --language B --cross 2,3   # 言語 B で、語頭 2 字形 × 語尾 3 字形
python3 voynich/affix.py --types            # 同じ語は 1 回と数える（異なり語単位）
```

出力される内容:

1. **字形の位置分布**: 各字形が 語頭 / 語中 / 語末 / 1 字形だけの語 のどこに出るか。90% 以上が 1 か所に集中するものに `*`。
2. **語頭・語尾の頻度**（長さ 1〜`--max-len` 字形）: 出現数・割合・**異なり語数**（いくつの別の語に付くか）・その形だけで 1 語になっている数。
3. **語頭×語尾のクロス表**（`--cross 語頭長,語尾長`, 既定 `1,2`）: 各セルは「出現数 (観測値/期待値)」。1 より大きければよく組み合わさり、小さければ避け合う。語頭と語尾が重ならないよう、両方の長さの合計以上の語だけを数えます。
4. **`--by` 指定時**: グループごとに、他のグループより多い語頭・語尾（長さ 1〜`--max-len` をまとめて G² で順位付け）。

| オプション | 既定 | 意味 |
|---|---|---|
| `--top` | 15 | 各表の件数 |
| `--max-len` | 3 | 語頭・語尾の最大長（字形数） |
| `--cross` | `1,2` | クロス表の 語頭長,語尾長 |
| `--cross-top` | 8 | クロス表に出す語頭・語尾の数 |
| `--min-glyph` | 50 | 位置分布の表に出す字形の最小出現数 |
| `--types` | — | 異なり語単位で数える（このとき「出現数」列は語数になります） |

### 結果の要点（全体, ZL3b）

- **語頭にしか出ない字形**: `q`（99.4%）。**語中だけ**: `e`, `i`, `h`。**語末だけ**: `n`（98.5%）, `m`（95.2%）。`y`, `r`, `l` も語末に偏る（86% / 75% / 55%）。
- **よくある語頭**: `qo-`（14.2%）, `che-`, `ok-`, `ot-`, `da-`, `she-`。**よくある語尾**: `-dy`（18.2%）, `-in`（15.9%）, `-ey`, `-ol`, `-ar`, `-or`, `-al`。
- **組み合わせの偏り**: `a-` と `-in` は期待値の 3.0 倍（`aiin`, `ain` 系）、`d-` と `-in` も 2.1 倍（`daiin` 系）。逆に `sh-`・`ch-` は `-in` を避け（0.3 倍 / 0.5 倍）、`-ey` や `-ol` と組み合わさる。
- **言語 A と B**: A は語頭 `cho-` `cth-` `sho-` と語尾 `-or` `-ol` `-chor` `-chol` が多い。B は語頭 `qok-` `l-` `ched-` `shed-` と語尾 `-edy`（B で 17.2%、A では 0.7%）`-dy` `-ain` が多い。
