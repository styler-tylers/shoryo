# ヴォイニッチ手稿 定量分析スクリプト集

René Zandbergen の **ZL 転写ファイル**（IVTFF 形式・EVA 表記, 版 3b / 2025-05-13）を読み込み、
ヴォイニッチ手稿の文章を数えて調べるスクリプト集です。標準ライブラリのみで動作します（Python 3.9+）。

| スクリプト | 内容 |
|---|---|
| `word_freq.py` | 単語頻度・基本統計・Zipf 指数 |
| `affix.py` | 語頭・語尾 |
| `line_position.py` | 行頭・行末・段落頭 |
| `line_forms.py` | 行頭形・行末形の検証 |
| `vocab_shift.py` | ページごとの語彙の移り変わり |
| `reorder.py` | 語彙の類似度から元の並びを推定（二つ折り単位） |
| `compare_transcriptions.py` | 主な指標を複数の転写で比べる |
| `spread.py` | Yale の IIIF 画像から見開き画像と綴じ目の拡大を作る（Pillow が必要） |
| `initials.py` | Yale の IIIF 画像から各頁の左上を切り出し、大きな頭文字を探すための一覧画像を作る（Pillow が必要） |
| `page_images.py` | 全頁の縮小画像を Yale の IIIF から取得（Pillow が必要） |
| `image_text.py` | 絵の色の特徴と文章の語彙の対応を調べる（Pillow・numpy が必要） |
| `labels.py` | ラベル（絵の部分の横の語）の性質、同じ頁の本文での言及、繰り返し、黄道十二宮での位置 |
| `pharma_labels.py` | 薬学セクションの「ラベル → 物」対応表の下書き（`notes/薬学ラベル対応表.csv`）を作る |
| `self_citation.py` | 自己引用説（近くの語を写して少し変えた）の検証。対照に自然言語のテキストも分析できる |

- 転写ファイル: https://www.voynich.nu/data/ZL3b-n.txt （初回実行時に `voynich/data/` へ自動ダウンロード。リポジトリには含めません）
- 他の転写: すべてのスクリプトで `--file IT2a-n.txt`（高橋健の転写）や `--file RF1b-e.txt`（参照転写）のようにファイル名だけを渡すと、同じく自動ダウンロードして使えます。
- 原本画像: Yale Beinecke MS 408 — https://collections.library.yale.edu/catalog/2002046

## 使い方

```sh
python3 voynich/word_freq.py                         # 全体の上位 30 語と基本統計
python3 voynich/word_freq.py --top 100 --csv voynich/out/freq.csv   # 全語の頻度表を CSV へ
python3 voynich/word_freq.py --language A            # Currier 言語 A のページのみ
python3 voynich/word_freq.py --illustration H --locus P   # 植物セクションの本文（ラベル除外）
python3 voynich/word_freq.py --by L                  # 言語 A / B を比較（特徴語つき）
python3 voynich/word_freq.py --by I --top 10         # 挿絵種別ごとに比較
python3 voynich/word_freq.py --help                  # 全オプション
```

### 絞り込み（カンマ区切りで複数可）

| オプション | 意味 | 値 |
|---|---|---|
| `--language` | Currier 言語 | `A`, `B` |
| `--hand` | 筆写者（ZL の `$H`。Davis の 5 筆写者分類と推定されるが出典未確認） | `1`〜`5` |
| `--illustration` | 挿絵種別 | `H` 植物, `A` 天文, `C` 宇宙論, `Z` 黄道, `B` 生物, `P` 薬学, `S` 星, `T` 文字のみ |
| `--quire` | クワイア | `A`〜`T` |
| `--page` | ページ | `f1r,f1v` など |
| `--locus` | 行の種類 | `P` 段落, `L` ラベル, `C` 円形, `R` 放射状 |

### 比較（`--by`）

ページ属性（`L` 言語, `H` 筆写者, `I` 挿絵, `Q` クワイア など）でグループに分け、
グループごとに統計・頻度表と **特徴語**（そのグループで他より有意に多い語。対数尤度比 G² で順位付け）を出力します。
属性が未指定のページは「未指定」グループになります。

## 単語化のルール（既定値）

| ZL の記法 | 意味 | 既定の扱い | 変更オプション |
|---|---|---|---|
| `.` | 単語区切り | 区切る | — |
| `,` | 不確かな単語区切り | 区切る | `--comma-join` で連結 |
| `[a:o]` | 異読 | 最初の読みを採用 | `--alt 1` で 2 番目 |
| `{ckh}` | 合字 | 括弧を外して中身を採用 | — |
| `?` | 判読不能文字 | その語を除外 | `--keep-uncertain` |
| `@185;` | 稀少文字 | そのまま 1 語に含める | `--drop-rare` で除外 |
| `<->` `<~>` | 挿絵による中断 | 単語区切り | — |
| `<!...>` `<%>` `<$>` | コメント・段落の始まり/終わり | 削除 | — |

注意:
- 筆写者・言語などの属性は**ページ単位**で判定します。行中の筆写者交代マーク（`<@H=2>` など、f115r の 2 箇所のみ）は反映しません。
- 平均語長は EVA の文字数です。`ch` や `sh` のように 2 文字で 1 字形を表すものも 2 文字と数えます。

## 実行例（全体）

```
総語数 (token)   : 38346
異なり語数 (type): 8093
タイプ/トークン比: 0.2111
Zipf 指数        : 1.022
  1  daiin  845  2.20%
```

# 語頭・語尾分析（`affix.py`）

単語を EVA の**字形単位**に分けて、語頭（接頭部）と語尾（接尾部）を調べます。
`ch` `sh` と台付きガロウズ `cth` `ckh` `cph` `cfh` は 1 字形、稀少文字 `@nnn;` も 1 字形として扱います
（例: `qokchedy` → `q o k ch e d y`）。絞り込み・`--by`・単語化の設定は `word_freq.py` と共通です。

```sh
python3 voynich/affix.py                    # 全体
python3 voynich/affix.py --by L             # 言語 A / B の特徴的な語頭・語尾
python3 voynich/affix.py --language B --cross 2,3   # 言語 B で、語頭 2 字形 × 語尾 3 字形
python3 voynich/affix.py --types            # 同じ語は 1 回と数える（異なり語単位）
```

出力される内容:

1. **字形の位置分布**: 各字形が 語頭 / 語中 / 語末 / 1 字形だけの語 のどこに出るか。90% 以上が 1 か所に集中するものに `*`。
2. **語頭・語尾の頻度**（長さ 1〜`--max-len` 字形）: 出現数・割合・**異なり語数**（いくつの別の語に付くか）・その形だけで 1 語になっている数。
3. **語頭×語尾のクロス表**（`--cross 語頭長,語尾長`, 既定 `1,2`）: 各セルは「出現数 (観測値/期待値)」。1 より大きければよく組み合わさり、小さければ避け合う。語頭と語尾が重ならないよう、両方の長さの合計以上の語だけを数えます。
4. **`--by` 指定時**: グループごとに、他のグループより多い語頭・語尾（長さ 1〜`--max-len` をまとめて G² で順位付け）。

| オプション | 既定 | 意味 |
|---|---|---|
| `--top` | 15 | 各表の件数 |
| `--max-len` | 3 | 語頭・語尾の最大長（字形数） |
| `--cross` | `1,2` | クロス表の 語頭長,語尾長 |
| `--cross-top` | 8 | クロス表に出す語頭・語尾の数 |
| `--min-glyph` | 50 | 位置分布の表に出す字形の最小出現数 |
| `--types` | — | 異なり語単位で数える（このとき「出現数」列は語数になります） |

### 結果の要点（全体, ZL3b）

- **語頭にしか出ない字形**: `q`（99.4%）。**語中だけ**: `e`, `i`, `h`。**語末だけ**: `n`（98.5%）, `m`（95.2%）。`y`, `r`, `l` も語末に偏る（86% / 75% / 55%）。
- **よくある語頭**: `qo-`（14.2%）, `che-`, `ok-`, `ot-`, `da-`, `she-`。**よくある語尾**: `-dy`（18.2%）, `-in`（15.9%）, `-ey`, `-ol`, `-ar`, `-or`, `-al`。
- **組み合わせの偏り**: `a-` と `-in` は期待値の 3.0 倍（`aiin`, `ain` 系）、`d-` と `-in` も 2.1 倍（`daiin` 系）。逆に `sh-`・`ch-` は `-in` を避け（0.3 倍 / 0.5 倍）、`-ey` や `-ol` と組み合わさる。
- **言語 A と B**: A は語頭 `cho-` `cth-` `sho-` と語尾 `-or` `-ol` `-chor` `-chol` が多い。B は語頭 `qok-` `l-` `ched-` `shed-` と語尾 `-edy`（B で 17.2%、A では 0.2%）`-dy` `-ain` が多い。

# 行頭・行末分析（`line_position.py`）

行の中の位置（行頭・行中・行末）によって、単語や字形の出方が変わるかを調べます。
自然言語の文章なら行の折り返しは語の中身とほぼ無関係なので、偏りがあれば
「行」が書き手にとって意味のある単位だった手がかりになります。

```sh
python3 voynich/line_position.py              # 全体（段落テキストのみ）
python3 voynich/line_position.py --by L       # 言語 A / B それぞれについても出力
python3 voynich/line_position.py --illustration H --top 20
```

- 既定では**段落テキスト（`--locus P`）だけ**を対象にします。ラベルは 1 行 1 語、円形テキストは行の区切りが物理的でないためです。
- 比較には 3 語以上の行を使い、行頭の語・行末の語を**行中の語**（行頭・行末以外）と比べます。
- **段落の最初の行**（`<%>` を含む行）は行頭の比較から、**段落の最後の行**（`<$>` を含む行）は行末の比較から除き、段落の最初の行は別の表で扱います。
- 「倍率」は、行頭（行末）での割合が行中での割合の何倍か。G² が大きいほど偶然では説明しにくい偏りです。

| オプション | 既定 | 意味 |
|---|---|---|
| `--top` | 12 | 各表の件数 |
| `--span` | 4 | 位置別の平均語長で、行頭・行末から何語目まで見るか |

### 結果の要点（全体, ZL3b, 段落テキスト 4,119 行）

- **段落の最初の語**: 84.4% がガロウズ字形（`k t p f` と台付き）で始まり、特に `p-` は 45.6%（他の行の行頭では 1.3%）。字形 `p` `f` は段落の最初の行に集中している（他の行の約 20 倍 / 15 倍）。
- **行頭**（段落の最初の行を除く）: 語頭 `y-` `s-` `d-` が行中の 2.5〜5 倍。`ych-` は 43 倍、`ysh-` は 83 倍。語 `dshedy` `saiin` `sol` `sor` が行頭に偏る。
- **行末**（段落の最後の行を除く）: 語尾 `-m` が行末の語の 16.9%（行中では 0.95%）、`-g` も 28 倍。`am` `dam` `oly` `-ry` `-om` が行末に偏る。
- **語長**: 行の 1 語目が最も長く（平均 4.97 字形, 2 語目は 4.30）、行末の語が最も短い（4.25）。
- **言語差**: 行末の `-m` の偏りは言語 B で特に強い（行中の 36 倍, A では 6 倍）。

これらは Currier（1976）以来指摘されている「行は機能的な単位らしい」という観察と一致します。

# 語彙の移り変わり分析（`vocab_shift.py`）

ページごとの語彙（単語の相対頻度）を比べて、どのページ同士が似ているかを調べます。
類似度は単語頻度ベクトルの**コサイン類似度**（0〜1）です。

```sh
python3 voynich/vocab_shift.py                       # 全体
python3 voynich/vocab_shift.py --language B          # 言語 B のページだけで（言語差の影響を除く）
python3 voynich/vocab_shift.py --by Q                # クワイアどうしの類似度行列
python3 voynich/vocab_shift.py --similar f1r         # f1r に語彙が似ているページ
python3 voynich/vocab_shift.py --feature glyph2      # 単語の代わりに字形の 2-gram で比べる
python3 voynich/vocab_shift.py --matrix-csv voynich/out/sim.csv   # 類似度行列を CSV へ
```

出力される内容:

1. **ページの関係ごとの類似度**: 隣り合うページ、同じ葉の表と裏、同じ二つ折り（bifolio）の別の葉、同じクワイア、同じセクション、同じ言語、同じ筆写者などの組ごとの平均。
   さらに、隣り合うページの類似度を、ページ順をランダムに並べ替えた場合と比べる**並べ替え検定**（p 値）。
2. **グループどうしの類似度行列**（既定では挿絵種別と言語。`--by` で変更）。
3. **少数のページに集中している語**: 語がページの大きさに比例してランダムに散らばったら何ページに出るはずかを計算し、実際のページ数との比（集中度）が小さい語。話題を表す語の候補です。
4. **`--similar ページ`**: そのページに語彙が最も似ているページ。

| オプション | 既定 | 意味 |
|---|---|---|
| `--feature` | `words` | 類似度に使う特徴（`words` 単語 / `glyph2` 字形の 2-gram） |
| `--min-words` | 50 | 分析に含めるページの最小語数（小さいページは類似度が不安定なため） |
| `--burst-min` | 15 | 集中度を計算する語の最小出現数 |
| `--trials` | 2000 | 並べ替え検定の回数（0 で省略） |
| `--top` | 20 | 各表の件数 |

既定では段落テキスト（`--locus P`）だけを対象にします。ページの順番は転写ファイルの順（＝現在の綴じ順）です。
**現在の綴じ順は元の順番と違う可能性が高い**（頁をまたぐ絵の存在など）ので、「隣り合うページ」は現在の綴じ順での隣にすぎません。
綴じ直しても変わらない「同じ葉の表と裏」「同じ二つ折りの別の葉」の方が信頼できる指標です（`notes/頁順の問題.md`）。

### 結果の要点（全体, ZL3b, 50 語以上のページ 193 ページ）

| ページの組 | 平均類似度 |
|---|---|
| 全ての組 | 0.236 |
| 言語が異なる（A と B） | 0.167 |
| 同じ言語 | 0.305 |
| 同じセクション | 0.253 |
| 同じクワイア | 0.368 |
| 隣り合うページ | 0.384（並べ替え検定 p = 0.0005） |
| 同じ二つ折りの別の葉 | 0.408 |
| 同じ葉の表と裏 | 0.424 |
| 現在の見開き（ある葉の裏と次の葉の表） | 0.352 |
| **二つ折りの中央見開き**（前の葉の裏と後ろの葉の表, 例: f78v と f81r） | **0.456** |

- **二つ折りの中央見開きが最も似ていて、現在の見開きより有意に似ている**（並べ替え検定 p = 0.002。高橋版でも 0.449 対 0.347, p = 0.003）。
  Layfield & Davis (2026) が LSA で示した「中央見開き 0.433 ＞ 表と裏 0.383 ＞ 現在の見開き 0.298」と同じ順で、別の方法（単語頻度のコサイン類似度）で独立に再現できた。
  二つ折り 1 枚ずつを開いて読む作り（singulion）だったという仮説と整合します（`notes/2026-11-10 ヴォイニッチ手稿 singulion 仮説の検証.md`）。

- **物理的に近いページほど語彙が似ている**。同じ二つ折りの別の葉（綴じた状態では離れていることが多い）は、隣り合うページと同じくらい似ている。言語 A / B のどちらかに絞っても同じ傾向が残る。二つ折りの紙 1 枚が書写の単位で、後で並びが変わったという見方と整合します。現在の並びでの隣接頁がランダムより似ているのは、同じ二つ折り・同じセクションの頁が今も近くにまとまっているためとも説明でき、現在の並びが正しい証拠にはなりません。
- **セクション（挿絵種別）は語彙をあまり決めていない**。植物セクションの中の類似度（0.234）は全体の平均とほぼ同じ。一方、生物・浴場セクション（0.608）や星・レシピセクション（0.476）は内部の語彙がよくまとまっている。
- **言語 A と B の差が最も大きな要因**。言語の異なるページの組は類似度が最も低い。
- **筆写者 2 と 3 は互いに語彙が近い**（0.352）。筆写者 1 は他の筆写者と離れている。
- **集中している語** は `qokain` `qokeedy` `qol` `shedy` `lchedy` など言語 B の語が多く、生物・浴場セクション（f75〜f84）や星・レシピセクション（f103〜f116）に集中する。言語 B だけに絞ると、`cheal` `lkain`（星・レシピ）、`qol` `olkain`（生物・浴場）、`ytaiin`（f86 の折り込み）などが局所的な語として残る。

# 行頭形・行末形の検証（`line_forms.py`）

`line_position.py` で見つかった「行頭に `y-` `s-` `d-` が多い」「行末に `-m` が多い」という偏りが、
**ふつうの語に行頭だけの字形が付いたもの / 行末だけ語尾が変わったもの**なのかを確かめます。

```sh
python3 voynich/line_forms.py                       # 既定: 行頭 y,s,d,o,q,ch,sh / 行末 m,g
python3 voynich/line_forms.py --by L --examples 0   # 言語 A / B それぞれ、例を省略
python3 voynich/line_forms.py --file IT2a-n.txt     # 高橋版で同じ検証
```

検証は 3 つ。いずれも行頭の語（段落の最初の行を除く）・行末の語（段落の最後の行を除く）を、**同じ字形で始まる（終わる）行中の語**と比べます。

1. **残りが行中の語か**: 最初の字形を取り除いた残りが、行中で 2 回以上使われる語か（`--vocab-min`）。
2. **残りの語頭字形の分布**: 残りがどんな字形で始まるかを、行中の語全体の語頭字形の分布と比べる（コサイン類似度「近さ」）。
3. **行頭だけの語**: 語そのものは行中でほぼ使われないのに、残りは行中の語であるもの。
4. **行末形**: 行末の `-m`（`-g`）を別の語尾（`--replace`、既定 削除,n,in,iin,r,l,s,y,dy）に置き換えると行中の語になるか。

### 結果の要点（ZL3b。高橋版 IT2a でもほぼ同じ値）

- **検証 1 は区別できない**。ヴォイニッチの語は組み合わせの自由度が高く、`y-` で始まる語は行頭でも行中でも 81% が「残りも行中の語」になる。この方法だけでは判定できない。
- **検証 2 が決め手**。行頭の `y-` 語の残りは 45% が `ch` `sh` で始まり（`ycheey` → `cheey`, `ychor` → `chor`, `yshey` → `shey`）、行中の語全体の始まり方に近い（近さ 0.56）。行中の `y-` 語の残りは 44% が `k` で始まり（`ykeey` など）、`ch` `sh` は 5% しかない（近さ 0.17）。`d-` も同様（0.48 対 0.30）。
- **行頭の `y-` 語の 45% は「行頭だけの語」**（ZL。高橋版では 40%）。例: `ychor` は行頭 15 回・行中 0 回だが、`chor` は行中 193 回。
- 言語 A でも B でも同じ傾向（`y-` の近さ: A 0.73 対 0.21、B 0.46 対 0.15）。
- **行末の `-m` は置き換えても区別できない**。`-m` を `-iin` `-r` `-l` に置き換えると行中の語になる割合は、行末の語でも行中の `-m` 語でもほぼ同じ（例: `-iin` 67% 対 67%）。`dam`↔`daiin`, `qokam`↔`qokain` のように対応はあるが、行末に限った現象ではない。

> 解釈: 行頭の `y-`（と `d-`）は、ふつうの語（とくに `ch-` `sh-` で始まる語）の前に**行頭だけで付く字形**である可能性が高い。
> 行末の `-m` は、`-iin` `-r` `-l` などと入れ替わる語尾の 1 つで、行末に出やすいだけで「行末専用の形」とまでは言えない。

# 元の並びの推定（`reorder.py`）

現在の綴じ順は元の並びと違う可能性が高い（`notes/頁順の問題.md`）ため、**語彙の似ている単位どうしが隣に来る並び**を探し、元の並びの候補として示します。
並べる単位は、綴じ直しても一体のまま残る**二つ折りの紙（bifolio）**が既定です（ZL の `$Q` `$B`。二つ折りでない単独の葉は葉として扱う）。
二つ折りの中でどちらの葉が前か、表裏の向きまでは推定しません。

```sh
python3 voynich/reorder.py                         # 二つ折り単位、全体（約 1 分）
python3 voynich/reorder.py --consensus             # 3 つの設定で並べ、一致した隣どうしを出す（約 2 分）
python3 voynich/reorder.py --within L              # 言語 A / B それぞれの中で並べる
python3 voynich/reorder.py --unit folio --language B
python3 voynich/reorder.py --link f67r1:f68r1      # 絵がつながる頁の組を必ず隣にする
python3 voynich/reorder.py --singulion --quire M,T --locus P,L,C,R   # singulion モデルで総当たり
```

方法:

1. 単位ごとに単語の頻度を集め、単位どうしの類似度（コサイン類似度。既定は tf-idf で、どの単位にも出る語を軽くする）を計算する。
2. 隣どうしの類似度の合計が最大になる並び（開いた経路）を、貪欲法＋2-opt＋or-opt を 20 回やり直して探す。
3. **ブートストラップ**: 各単位の語を同じ数だけ復元抽出し直して並べ替えることを 30 回行い、同じ隣どうしになった割合（支持率）を出す。
4. `--consensus`: 特徴と重みの 3 つの設定（単語/tf-idf、単語/そのまま、字形 2-gram/そのまま）で 1〜3 を行い、設定をまたいで支持された組を出す。

| オプション | 既定 | 意味 |
|---|---|---|
| `--unit` | `bifolio` | 並べる単位（`bifolio` / `folio` / `page`） |
| `--within` | — | 属性のグループごとに分けて並べる |
| `--feature` / `--weight` | `words` / `tfidf` | 類似度に使う特徴と重み |
| `--min-words` | 100 | 並べる単位の最小語数 |
| `--link` | — | 必ず隣にする頁の組（`頁:頁` をカンマ区切り） |
| `--bootstrap` / `--strong` | 30 / 0.7 | ブートストラップの回数 / 「確かな隣」とみなす支持率 |
| `--consensus` / `--consensus-min` | — / 2 | 3 設定での一致を見る / 何設定以上で支持された組を出すか |
| `--singulion` | — | 二つ折り 1 枚ずつを開いて読む作りを仮定し、クワイアごとに総当たりで並べる（下記） |
| `--order` | — | `--singulion` で評価する並び（例: `77\|82,78\|81,75\|84,76\|83,79\|80`）。複数指定可 |
| `--start` | — | `--singulion` で、指定した二つ折りから始まる並びの最良も出す（例: 大きな頭文字の頁 `76\|83,105\|114`） |

### singulion モデルでの総当たり（`--singulion`）

Layfield & Davis (2026) は、各二つ折りを「前の葉の表 → 裏 → 後ろの葉の表 → 裏」の 4 頁として順に読む作り（singulion）だったと推定しました。
この作りで二つ折り X の次に Y を綴じると、X の最後の頁と Y の最初の頁が見開きになります。
`--singulion` は、この見開きの類似度の平均が最大になる二つ折りの並びを、クワイアごとに**総当たり**で探します（`--exact-max` 枚まで。既定 8 枚 = 40,320 通り）。

**星・レシピのクワイア T（6 枚, 720 通り）**: 1 位は `105|114, 104|115, 106|113, 107|112, 108|111, 103|116` で、**Layfield & Davis (2026) の最適な並びと完全に一致**。
ZL・高橋版 × 重み 2 種 × 対象テキスト 2 種の 5 通りの設定すべてで 1 位でした。現在の並びは 720 通り中 211〜377 位。

**生物・浴場のクワイア M（5 枚, 120 通り）**: 設定によって 1 位が変わり、不安定。論文の最適な並び `77|82, 78|81, 75|84, 76|83, 79|80` は 2〜61 位。
ただし `75|84` の次に `78|81` が来る並びが上位に多く、論文も「75|84 と 78|81 が並ぶ」点を指摘している（`reorder.py` の通常の並べ替えでも M1—M4 として一貫して支持）。

**全クワイア**（`--quire` を付けずに実行。折り込みを含むクワイアは対象外）: 5 設定で 1 位が完全に一致したのは T と、植物のクワイア C（`20|21, 19|22, 18|23, 17|24` = 現在の入れ子を内側から外側へ）だけ。
植物のクワイア（4 枚, 24 通り）は重みの付け方で 1 位が変わることが多く、弱い証拠です。詳細は研究ノート第 4 回の検証 4。

なお、ZL の段落記号ではすべての頁が段落の始まりで始まるため、「段落が二つ折りをまたいでつながるか」で並びを確かめることはできません（検証 5）。

# 絵と文章の対応（`image_text.py`）

「文章が同じ頁の絵を説明しているなら、絵の特徴が似た頁どうしは語彙も似ているはず」という仮説を、絵の**色**で試す予備実験です。

```sh
python3 voynich/page_images.py                 # 先に全頁の画像（幅 500 px）を取得（20〜30 分）
python3 voynich/image_text.py                  # 既定: 植物セクション・言語 A
python3 voynich/image_text.py --language B
python3 voynich/image_text.py --illustration H,B,S,P,Z,C,A,T --language A,B   # 全セクション（対照）
```

- 色の特徴: 頁の縁 7% を除き、HSV で緑・青・赤・黄の顔料の画素が頁に占める割合を測る（境目は経験的なもの）。
- マンテル検定: 頁の組ごとの「語彙の類似度（tf-idf のコサイン）」と「色の類似度（色の特徴の距離の負）」の相関 r を、頁を入れ替えた場合と比べる。
- 色と結びつく語: 色の多い上位 1/4 の頁とそれ以外で G² を計算し、頁を入れ替えたときの最大 G² の 95% 点と比べる。

### 結果（ZL3b）

| 対象 | 頁数 | r（全ての組） | p | r（同じクワイアを除く） | p |
|---|---|---|---|---|---|
| 植物・言語 A | 91 | -0.002 | 0.49 | 0.003 | 0.46 |
| 植物・言語 B | 27 | 0.007 | 0.45 | 0.020 | 0.40 |
| 全セクション（対照） | 169 | **0.130** | **0.001** | 0.026 | 0.15 |

- **植物セクションの中では、絵の色と語彙に対応は見られなかった**。色と結びつく語も、偶然の最大を超えるものは 1 つも無い。
- 全セクションでは対応が出る（r = 0.13）ので、方法自体は対応があれば検出できる。ただしそれはセクション（とクワイア）の違いによるもので、同じクワイアの組を除くと消える。
- 彩色は線描より後に別の人が行ったという指摘もあり（本研究では未確認）、色は絵の内容の指標としては粗い。形（根・葉・花の種類）など、より細かい特徴での検証が次の段階。

# ラベルの分析（`labels.py`）

ラベルは、絵の個々の部分（薬草のかけら・薬壺・ニンフ・星など）のすぐ横に書かれた 1〜数語です。
「説明する人と描く人が別」なら、ラベルは絵の部分の名前で、本文はその部分に触れているはず、という考えを確かめます。

```sh
python3 voynich/labels.py                     # 全ラベル
python3 voynich/labels.py --types Lf,Lc       # 薬学のラベルだけ
python3 voynich/labels.py --file IT2a-n.txt   # 高橋版で
```

ラベルの種類（ZL のロカス種別）: `Lf` 薬学の薬草のかけら / `Lc` 薬学の薬壺 / `Lz` 黄道十二宮のニンフ / `Ls` 天文の星・月 / `Ln` 生物・浴場のニンフ / `Lt` 生物・浴場の管・池など / `L0` その他。
1 字形だけのラベル（記号の列が多い）は除きます（`--min-glyphs`）。

### 結果の要点（ZL3b, 2 字形以上のラベル 934 語）

| 種類 | 語数 | 異なり | 平均長 | o- で始まる | 本文にも出る |
|---|---|---|---|---|---|
| Lz 黄道十二宮のニンフ | 343 | 279 | 5.45 | 67.3% | 57.7% |
| Lf 薬学の薬草 | 203 | 190 | 5.34 | 50.7% | 55.2% |
| Lc 薬学の薬壺 | 36 | 36 | 6.69 | 52.8% | **8.3%** |
| Ln 生物・浴場のニンフ | 64 | 60 | 4.86 | 54.7% | 81.2% |
| （参考）本文の語 | 34,940 | 7,164 | 4.46 | 20.5% | − |

- **ラベルは本文の語と形が違う**: `o-` で始まるものが 5〜7 割（本文は 2 割）で、やや長い。ほとんどが 1 回きりの語。薬壺のラベルは本文にほぼ出ない。
- **同じ頁の本文での言及は、偶然とほとんど変わらない**: ラベルを同じセクションの別の頁に入れ替えた場合と比べて、完全一致 10.3% 対 9.3%（p = 0.12）。語頭の `qo/o/y/q` を除いた語幹では 16.0% 対 14.0%（p = 0.014）とわずかに多いが、差は 2 ポイントほど。薬学だけ（p = 0.23〜0.42）、生物・浴場だけ（p = 0.11〜0.30）では有意でない。高橋版でも同じ傾向（語幹 16.4% 対 14.9%, p = 0.04）。
- **黄道十二宮の同じラベルは、円の中の同じ位置にあるわけではない**（位置の差 0.243 対 入れ替え 0.250, p = 0.32）。ラベルが日付や順番の名前だという見方は支持されない（ZL のラベル順は円の外側・内側の区別をしていない点に注意）。
- `otaly` `okol` `okal` などは、黄道十二宮・薬学・生物など別々のセクションのラベルとして繰り返し現れる（103 語が 2 頁以上）。同じ物に同じ名前が付いているかは、画像で確かめる必要がある。
- 薬学の f88r と f99v は `otoky` `otaly` `otor` の 3 つのラベルを共有する。画像で比べると、似た形の根に同じラベルが付いているようにも見えるが、f88r ではラベルが 2 つの物の間にあり、対応づけに決め手がない（研究ノート第 6 回の追加検証 1）。
- ラベルの `o-` の次の字形は `t` `k` が 7 割で、本文の `o-` 語と同じ型。ラベル専用の付け足しではなさそう（追加検証 2）。

# 自己引用説の検証（`self_citation.py`）

自己引用説（Timm & Schinner）は、書き手が少し前に書いた語（同じ行の前の語や上の行の語）を写しながら字を少し変えて
文章を作った、とする説です。3 つの予測を確かめ、写しの起こらない**ラテン語の文章**（機械的に 8 語/行で折り返したもの）を対照にします。

```sh
python3 voynich/self_citation.py                        # 言語 A・B（段落テキスト）
python3 voynich/self_citation.py --file IT2a-n.txt
curl -sSLO https://www.gutenberg.org/cache/epub/218/pg218.txt   # カエサル『ガリア戦記』I〜IV（ラテン語, パブリックドメイン）
python3 voynich/self_citation.py --control pg218.txt     # 対照
```

1. **近くの語の写し**: 同じ行の前の語と 1 つ上の行に、同じ語か字形が 1 つだけ違う語がある割合を、別の頁の同じ位置の行と比べる。
2. **行の距離による減衰**: k 行上（k = 1〜8）にほぼ同じ語がある割合（同じ頁 ÷ 別の頁）。
3. **縦の位置**: 1 つ上の行の「字形が 1 つだけ違う語」が真上にあるか（行の中の相対位置の差、上の行の語順を入れ替えた場合と比較）。
   行頭・行末を除いた場合と、上の行を**別の頁の行**に替えた対照も出す。

### 結果（段落テキスト）

| | 1. 写しの倍率（同じ頁 ÷ 別の頁） | 2. 倍率 k=1 → k=8 | 3. 真上への偏り（行頭・行末を除く） | 3 の対照（別の頁の行） |
|---|---|---|---|---|
| ヴォイニッチ 言語 A（ZL） | 1.47 | 1.53 → 1.35 | 0.239 対 0.248, **p = 0.016** | p = 0.21 |
| ヴォイニッチ 言語 B（ZL） | 1.48 | 1.60 → 1.42 | 0.258 対 0.263, **p = 0.05** | p = 0.29 |
| ヴォイニッチ 言語 A（IT） | 1.50 | 1.57 → 1.34 | 0.240 対 0.250, **p = 0.007** | p = 0.93 |
| ヴォイニッチ 言語 B（IT） | 1.49 | 1.64 → 1.44 | 0.257 対 0.263, **p = 0.03** | p = 0.65 |
| ラテン語『ガリア戦記』 | 1.07 | 1.19 → 1.14（一定しない） | 0.275 対 0.276, p = 0.50 | − |
| ラテン語 デカルト『省察』 | 1.19 | 1.34 → 1.13 | 0.269 対 0.266, p = 0.65 | − |

- **写しの倍率はラテン語より高い**（1.5 倍 対 1.1〜1.2 倍）。近くにほぼ同じ語が出やすい。ただし、話題が局所的に偏るだけでも倍率は上がる。
- **行の距離による減衰は、ラテン語（デカルト）にもある**。この検証だけでは自己引用と話題の偏りを区別できない。
- **真上への偏りは、ヴォイニッチでだけ出る**（2 つの転写・2 つの言語のすべて）。行頭・行末を除いても残り、上の行を別の頁の行に替えると消えるので、「行の中の位置ごとに語の型が決まっている」ことでは説明できない。**実際に上の行を見て書いた**ことを示す。
- ただし**偏りは小さい**（位置の差が 2〜4% 縮む程度）。文章全体が写しで作られたと言えるほどの強さではない。
